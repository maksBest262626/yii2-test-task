# Yii2 Book Catalog

Каталог книг на Yii2 + MySQL с разграничением прав доступа (гость / пользователь).

## Требования

- [Docker](https://docs.docker.com/get-docker/) >= 20.10
- [Docker Compose](https://docs.docker.com/compose/install/) >= 2.0
- `make`

## Быстрый старт

```bash
make install
```

Команда выполнит всё необходимое:
1. Соберёт Docker-образы
2. Установит Composer-зависимости
3. Запустит контейнеры (PHP, Nginx, MySQL)
4. Применит миграции базы данных

**Результат доступен по адресу:** http://localhost:8080

## Команды управления

| Команда          | Описание                                      |
|------------------|-----------------------------------------------|
| `make install`   | Первоначальная установка и запуск проекта     |
| `make up`        | Запустить контейнеры                          |
| `make down`      | Остановить и удалить контейнеры               |
| `make restart`   | Перезапустить контейнеры (без пересоздания)   |
| `make build`     | Пересобрать Docker-образы                     |
| `make logs`      | Показать логи всех контейнеров                |
| `make shell`     | Открыть bash в PHP-контейнере                 |
| `make migrate`   | Применить миграции базы данных                |
| `make ps`        | Статус контейнеров                            |

## Стек

- **PHP** 8.4
- **Nginx** 1.25
- **MySQL** 8.0
- **Yii2** basic template

## Техническое задание

### Описание

Каталог книг на Yii2 + MySQL. Книга может иметь несколько авторов.

### Сущности

**Книга:**
- Название
- Год выпуска
- Описание
- ISBN
- Фото обложки

**Автор:**
- ФИО

Связь: книга может иметь несколько авторов (many-to-many).

### Права доступа

| Роль                           | Возможности                                                      |
|--------------------------------|------------------------------------------------------------------|
| Гость (неаутентифицированный)  | Просмотр каталога, подписка на автора по номеру телефона        |
| Пользователь (авторизованный)  | Просмотр + полный CRUD книг и авторов                           |

### Отчёт

ТОП-10 авторов по количеству книг за выбранный год. Доступен всем пользователям (включая гостей).

### Подписка и SMS-уведомления (бонус)

- Гость может подписаться на конкретного автора, указав номер телефона
- При добавлении новой книги автора подписчик получает SMS-уведомление
- Отписка не требуется
- SMS через [smspilot.ru](https://smspilot.ru/) (тестовый ключ-эмулятор, реальной отправки нет)

### Уточнения к заданию

1. Web-приложение (не API)
2. Авторизация нужна
3. Фото обложки — любой вариант хранения (файловое хранилище)
4. Отчёт — отдельная страница, доступна всем
5. Подписка — на конкретного автора, не на совместные произведения
6. Гость — неаутентифицированный пользователь; для подписки вводит номер телефона
7. Функционал администратора не нужен
8. CRUD распространяется на книги и авторов
9. Автор книги — не пользователь системы
10. Стек: PHP 8+, MySQL/MariaDB, Yii2 basic template, миграции (дамп БД не нужен)
