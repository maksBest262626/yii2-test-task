# Yii2 Book Catalog

Каталог книг на Yii2 + MySQL с разграничением прав доступа (гость / пользователь).

## Требования

- [Docker](https://docs.docker.com/get-docker/) >= 20.10
- [Docker Compose](https://docs.docker.com/compose/install/) >= 2.0
- `make`

## Быстрый старт

```bash
make install
```

Команда выполнит всё необходимое:
1. Соберёт Docker-образы
2. Установит Composer-зависимости
3. Запустит контейнеры (PHP, Nginx, MySQL)
4. Применит миграции базы данных

**Результат доступен по адресу:** http://localhost:8080

## Команды управления

| Команда          | Описание                                      |
|------------------|-----------------------------------------------|
| `make install`   | Первоначальная установка и запуск проекта     |
| `make up`        | Запустить контейнеры                          |
| `make down`      | Остановить и удалить контейнеры               |
| `make restart`   | Перезапустить контейнеры                      |
| `make build`     | Пересобрать Docker-образы                     |
| `make logs`      | Показать логи всех контейнеров                |
| `make shell`     | Открыть bash в PHP-контейнере                 |
| `make migrate`   | Применить миграции базы данных                |
| `make ps`        | Статус контейнеров                            |

## Конфигурация окружения

Скопируйте `.env.example` в `.env` для переопределения переменных по умолчанию:

```bash
cp .env.example .env
```

| Переменная        | Значение по умолчанию | Описание                   |
|-------------------|-----------------------|----------------------------|
| `APP_PORT`        | `8080`                | Порт приложения            |
| `DB_PORT`         | `3306`                | Порт MySQL                 |
| `DB_NAME`         | `yii2_catalog`        | Имя базы данных            |
| `DB_USER`         | `yii2`                | Пользователь БД            |
| `DB_PASSWORD`     | `yii2password`        | Пароль пользователя БД     |
| `DB_ROOT_PASSWORD`| `rootpassword`        | Пароль root MySQL          |

## Стек

- **PHP** 8.2-fpm
- **Nginx** 1.25
- **MySQL** 8.0
- **Yii2** basic template

## Архитектура задания

**Сущности:**
- Книга — название, год выпуска, описание, ISBN, фото обложки
- Автор — ФИО (книга может иметь несколько авторов)

**Права доступа:**
- Гость — просмотр + подписка на новые книги автора
- Пользователь — просмотр, добавление, редактирование, удаление

**Отчёт:** ТОП-10 авторов по количеству книг за выбранный год (доступен всем)

**Бонус:** SMS-уведомление через [smspilot.ru](https://smspilot.ru/) при появлении новых книг у автора из подписки
